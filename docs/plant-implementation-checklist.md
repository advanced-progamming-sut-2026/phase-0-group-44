## Shared architecture and test coverage

- `CsvPlantRepository` parses and validates all 69 rows and requires a non-empty bonus classification source.
- `PlantRegistry` is the single definition lookup used by collection display, purchase validation, selection, factory construction, upgrades, cooldowns, and gameplay.
- `PlantBehaviorFactory` contains registrations only for the 57 mandatory rows. It fails startup if a mandatory row has no strategy.
- `PlantStats` applies level 2–4 changes cumulatively and only to the statistic named by each CSV upgrade.
- `GameMap` enforces water/support, primary, and armor layers; direct projectiles consult blocking obstacles while lobbers do not.
- `Projectile`, `Zombie`, and reusable effects implement lane collision, piercing, fire/ice interaction, poison armor bypass, splash, butter stun, and bouncing.
- `PlantCard` caps levels at four and centralizes increasing seed-packet and coin costs.
